# v0.1.0 验证记录

验证日期：2026-10-10。开发环境：Windows x64、Go 1.27.2；浏览器检查使用 Playwright 1.62.1 和本机 Microsoft Edge。

## 已完成

- `go test ./...`：通过，包括移植的原版机器人、牌型和规则引擎测试。
- `go vet ./...`：通过。
- 真人牌桌测试：350 个固定种子，覆盖弃牌、跟注、最小加注、全下，每次真人行动后重新加载，确认继续牌局一致、结算筹码守恒。
- 信息隔离测试：A 看见弃牌者底牌但不见未来公牌；B 看见固定未来公牌但不见对手底牌；机器人不会因为 A/B 模式而收到不同信息。
- 存档与统计测试：A/B 分组、BB/100、会话和最近手数窗口、历史分页、未结束手牌恢复、重复动作竞争、写盘失败回滚、损坏存档保护。
- 本地服务测试：动作参数校验、跨站请求边界、主机名限制、单实例存档锁和再次启动时的地址校验。
- 真实浏览器操作：手动加注／跟注／全下／弃牌、刷新、杀进程后重新启动恢复、切换 A/B、分组统计、复盘、CSV 导出、新会话保留旧历史。
- 界面检查：1440 像素桌面和 390 像素手机宽度，无横向溢出；浏览器测试未报告页面脚本错误。README 截图来自隔离的测试存档。

## 验证范围

Windows 是本次实际浏览器操作验证的平台。GitHub CI 另在 Windows、macOS、Linux 执行了后端测试与构建，均通过。发布脚本为三个系统各生成 x64 和 ARM64 构建；交叉编译成功不等于已在每种设备上完成桌面界面验证。发布包未签名或公证。

本机没有 C 编译器，因此未在本机执行 race detector；GitHub CI 的 Linux race 检查已通过。参见 [v0.1.0 源码的首次完整 CI 记录](https://github.com/wykhao/Poker_Superpower_Simulator/actions/runs/38095686161)。

测试验证程序规则、信息权限和记录一致性，不证明机器人等同真人，也不证明任何能力的理论最优收益。最终 A/B 成绩取决于真人的决策与样本量。
